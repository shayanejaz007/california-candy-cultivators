# Documentation index

This project is a production-oriented Next.js catalog/inquiry application. Read **SUPABASE_SETUP**, **ENVIRONMENT_VARIABLES**, **DEPLOYMENT**, **SECURITY**, and **CMS_GUIDE** before launch.

The application intentionally has no checkout or payment flow. Public visitors browse the catalog and submit inquiries.


## Runtime diagnostics

After deployment, open `/api/health`. See `docs/RUNTIME_DIAGNOSTICS.md` for status meanings.
